# 05 · 常见坑

格式固定三列：**症状 → 原因 → 处理**。对不上就在这里加一条，别在脑子里记。

| 症状 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: No module named 'openai'` | 本机 Python 没装 openai，真实模式起不来 | 先用 `python app/hello_agent.py --mock` 排练（零依赖）；要真跑再 `pip install openai` |
| 终端里中文全是乱码（如 `[��������]`） | Windows 控制台默认 GBK，Python 输出 UTF-8 | PowerShell 里先 `chcp 65001`，或设 `$env:PYTHONIOENCODING="utf-8"` |
| `git : 无法将"git"项识别为 cmdlet` | 这台机器没装 git | 用 `python scripts/snapshot.py v0.0.1` 生成快照；装好 git 后 `git init` 接管历史 |
| `node` 命令找不到 | Node 没进 PATH（DSH 自带的那份在私有目录） | `smoke.py` 会自动探 `NODE_BIN` 环境变量与 DSH 自带路径；手动指定：`$env:NODE_BIN="C:\...\node.exe"` |
| 网盘里的视频打不开 / 只有几 MB | 文件名以 `.baiduyun.p.downloading` 结尾，说明还没下完 | 回网盘把 5 个模块视频下完再看；代码与 PPT 不依赖视频 |
| `check.py` 报明文卡号 | 源码里出现了 16 位连续数字 | 改成 `6222 0202 0011 1234` 分组写法，或只保留 `****1234`；`mask()` 只取后四位，行为不变 |
| `check.py` 报 `TODO/待实现` | 写了占位没落地 | 要么当场实现，要么从代码里删掉、把缺口写进自述的「不足」 |
| 网页 Demo 打开是空白 | 用了 `file://` 且浏览器拦截了脚本 | 本页是自包含单文件，正常双击可跑；若空白，F12 看 Console，多半是浏览器插件拦截 |
