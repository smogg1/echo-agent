# Day 3 演示脚本：引导 / 冻结解冻 / 电话 / 审计筛选

> 这条脚本专门覆盖 v0.9.0 新增的能力。约 4 分钟。

## 一、逐步引导支持自由金额（1 分钟）

1. 点 **🧭 一步步办**
2. 选 **小王** → 出现 `100 元 / 500 元 / 1000 元 / 其他金额 / 先不转了`
3. **不点按钮，直接在输入框打 `200`** → 应弹出确认卡：`给「小王」转 200.00 元，对吗？`
4. 再试 `三千`（中文）与 `1250.50`（小数），都应被接住

要点：快捷额度只是快捷方式，**金额不限于那三个**。

## 二、冻结与解冻（1 分钟）

1. 说 **我卡好像丢了** → 🟢 自动冻结（止损优先），提示"正式挂失要人工核验"
2. 说 **转给小王 100 元** → 确认后返回 `❌ 卡已临时冻结，转账未执行`
3. 说 **卡找回来了，帮我解冻** → 🟡 需要确认 → 确认后恢复用卡
4. 再说 **转给小王 100 元** → 成功；紧接着问 **查一下本月账单** → 账单里能看到 `转账给小王 100.00 元`

要点：**转账计入账单**，所以"余额"和"账单"永远对得上。

## 三、电话模式（40 秒）

1. 点 **📞 电话模式** → 右下角出现模拟来电界面，提示会被念出来
2. 按 **1**（查余额）→ 播报并记录
3. 点 **挂断** → 面板关闭；此时再按数字不会有反应

要点：电话通道**大额直接拒绝**（超过单笔限额就让你用手机或去柜面）。

## 四、审计筛选（30 秒）

1. 先做一笔超限转账（`转给小王 5000 元`）
2. 右侧审计栏点 **已拦截** → 只剩拦截记录
3. 点 **已执行** → 只剩查询与已确认的操作
4. 点 **全部** → 恢复

## 五、无障碍（40 秒）

1. 点 **A+ 大字** → 气泡、问句、按钮一起变大
2. 点某条 Agent 消息旁的 **🔊** → 只读那一条
3. 确认卡上点 **🔊 再听一遍** → 不重新发起操作，只重读问句
4. 点 **🎤 说话** → 支持的浏览器里边说边显示转写；不支持会明确提示

## 六、六个场景全覆盖（v0.11.0 新增，每条 20 秒）

| 说法 | 看到什么 |
|---|---|
| `转给小李 100 元` | 🟡 不在通讯录也能转，确认后成功（账户显示「未登记账户」） |
| `转给小李 500 元` | 🔴 超过新收款人 200 元额度 → 拦截，并给"先转小额试试"的建议 |
| `转给小王 100 元 备注房租` | 🟡 备注作为附言写进结果，不进判定 |
| `每月 1 号转 500 给小王` | 🟡 定时转账，回显下次执行时间 |
| `三个人 AA 一共 300 元` | 🟡 每人 100.00 元，生成 3 条收款请求 |
| `把限额调到 2000` | 🟡 只**提交申请**，期间限额仍是 1,000.00 元 |
| `申请一张卡` | 🟡 虚拟卡尾号 8801，额度 500.00 元 |
| `什么时候扣费` | 🟢 未来 30 天续费清单 + 最早一笔倒计时 |
| `有哪些自动续费` | 🟢 按名称识别"像自动续费"的扣款（注明是启发式） |
| `我老伴生日快到了` | 🟡 生日方案：锁预算 + 提前 2 天提醒订花 |
| `我的理财` / `申购 500 元` | 🟢 持仓 / 🟡 小额申购成功 |
| `申购 10000 元` | 🔴 超过 5,000 元免验证额度 → 拦截 + 专属建议 |
