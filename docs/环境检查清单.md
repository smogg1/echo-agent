# 模块四 · 最小闭环 —— 环境检查清单

> 上课 / 录课前逐项过一遍，全部 ✅ 即可开讲。任何一项不过，先按对应「处理办法」修复。

## 一、基础环境（必查）

| # | 检查项 | 检查命令 / 方法 | 通过标准 | 不过的处理办法 |
|---|--------|----------------|----------|----------------|
| 1 | Python 版本 | `python3 --version` | ≥ 3.8 | 到 python.org 或 brew 安装新版本 |
| 2 | openai 库 | `python3 -c "import openai"` | 无报错 | `pip3 install openai`（或 `--user` 安装） |
| 3 | 演示文件在位 | `ls hello_agent.py` | 文件存在 | 从课程仓库重新拉取 |

## 二、大模型接入（真实模式必查，Mock 模式可跳过）

| # | 检查项 | 检查命令 / 方法 | 通过标准 | 不过的处理办法 |
|---|--------|----------------|----------|----------------|
| 4 | API Key | `echo $BANK_LLM_API_KEY` | 非空，sk- 开头 | `export BANK_LLM_API_KEY=sk-xxx` |
| 5 | 接口地址 | `echo $BANK_LLM_BASE_URL` | 与所用厂商一致 | GLM 默认已内置；DeepSeek/Qwen 需手动 export |
| 6 | 模型名 | `echo $BANK_LLM_MODEL` | 厂商控制台里存在的模型 | 默认 `glm-4-flash`，按需 export 覆盖 |
| 7 | 网络连通 | `curl -sI $BANK_LLM_BASE_URL` | 有 HTTP 响应 | 检查网络 / 代理 / 厂商服务状态 |
| 8 | 额度余量 | 厂商控制台查看 | 余额 / 额度充足 | 充值或换备用 key（录课尤其要查） |

## 三、演示链路自检（开讲前 5 分钟跑一遍）

| # | 检查项 | 操作 | 通过标准 |
|---|--------|------|----------|
| 9 | Mock 排练可用 | `python3 hello_agent.py --mock` | 打印意图理解→工具调用→工具返回，回复含「余额 9900」 |
| 10 | 真实模式闭环 | `python3 hello_agent.py`，输入「转给小王 100 块」 | 出现 `[工具调用] transfer(...)`，回复与工具结果一致 |
| 11 | 防幻觉红线 | 确认终端有 `[工具调用]` / `[工具返回]` 打印 | 有打印 = 真调了工具；只有文字回复 = 模型在演戏，不能用 |
| 12 | 上下文传递 | 连问「查余额」→「转 100 给小王」→「还剩多少」 | 最后答的是转账后的余额 |

## 四、兜底预案

- 现场没网 / key 失效 → `./一键启动.sh --mock` 走内置剧本，链路照样完整演示；
- 建议课前把 `--mock` 输出截图存一份，极端情况直接放图讲。
